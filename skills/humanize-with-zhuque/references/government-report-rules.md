# 政府报告去 AI 味规则

本规则整理自用户提供的《去除AI味规范.docx》。用于政府报告、公文、工作总结、调研报告、讲话稿、汇报材料、通知和请示。用户后续提供的新规则优先。

## 目录

1. 目标与边界
2. 输入诊断
3. 文种结构
4. 事实密度
5. 改写规则
6. 评分标准
7. 输出与禁区

## 1. 目标与边界

- 保持公文庄重、平实、简洁、克制，不改成自媒体、散文或评论。
- 保持信息守恒，不新增无依据事实，不删除关键信息，不改变数字、时间、政策名称、单位、人名、责任主体和引用归属。
- 把“谁负责、做了什么、通过什么机制、到什么节点、产生什么结果”作为事实密度的核心。
- 对无法核实或缺失的内容标注 `【待核实】` 或 `【待补】`，不得自动填充。
- 区分必要套话与空洞套话。“贯彻落实”“扎实推进”“高度重视”等词可以保留，但必须有事实支撑。
- 为每处实质修改保留原因和可追溯依据。

## 2. 输入诊断

先确认：

- 文种及行文关系
- 用途、受众、时效和密级
- 已知数据、时间、政策依据、会议部署、责任单位和成果
- 缺失的责任主体、动作、机制、节点和结果

如果没有充分事实资料，只做语言层清理，并输出待补事实清单。不要做事实性扩写。

## 3. 文种结构

### 通知

明确依据、事项、要求、时间和责任单位。

### 报告

按情况、做法、成效、问题和下一步组织内容。

### 请示

坚持一文一事，明确请求事项和理由。

### 工作总结

写清数据、做法、问题和计划。

### 调研报告

写清背景、方法、发现、分析和建议。

### 讲话稿

结合场合、对象、重点和要求组织内容。

同时检查标题、主送机关、正文、落款、日期和附件说明是否与文种一致。文种或行文关系错误时，先修正结构，再清理语言。

## 4. 事实密度

逐段检查：

- 是否只有抽象表述
- 是否缺少责任主体
- 是否缺少数据或可核查成果
- 是否缺少工作机制
- 是否缺少时间节点
- 是否缺少具体结果
- 是否只有正确但空泛的套话

需要补充但原文没有的事实，列入待补清单，不得推测。

## 5. 改写规则

| AI 痕迹 | 常见表现 | 处理方式 |
|---|---|---|
| 意义膨胀 | “重大意义”“深远影响”“新高度”“新台阶”却无事实 | 删除，或改成有依据的成果 |
| 假深刻 | “深刻认识到”“准确把握”“提高站位”却无行动 | 改成具体会议、文件或动作 |
| 模糊主体 | “相关部门”“有关方面”“各地各部门” | 明确责任单位；未知则标待核实 |
| 规则三连 | “持续强化、不断完善、全面推动” | 拆成具体动作、时间和结果 |
| 同义词轮换 | 推动、推进、促进、深化、强化机械轮换 | 保留最准确的词，删掉重复 |
| 万能结论 | “取得显著成效”“迈上新台阶”“奠定基础” | 用数据或具体成果替代 |
| 高频黑话 | 赋能、抓手、闭环、颗粒度、底层逻辑、组合拳等 | 改成具体动作或常用公文表达 |
| 破折号滥用 | 大量破折号和夹注 | 改为句号、逗号、冒号或独立句 |
| 排比堆叠 | 三项以上抽象排比 | 保留必要项，其余具体化 |
| 模板结构 | “首先、其次、最后”或空洞“一二三” | 结构确有检索作用时保留，并填入事实 |
| 中英夹杂 | 无必要英文术语 | 改成规范中文；专有名词除外 |
| 宏大开场 | 可套用到任何主题的时代背景 | 从本报告的具体情况切入 |
| 升华结尾 | 与正文无关的愿景和口号 | 用具体任务、问题或节点收口 |

不要把所有句子口语化。公文中的中立、平实和规范表达本身就是合适的人声。不要故意加错别字、口头禅、虚构经历或“装人味”的瑕疵。

## 6. 评分标准

每项 20 分，总分 100 分：

1. 事实密度：是否包含数据、时间、主体、机制和结果。
2. 主体明确：责任单位、责任人和配合单位是否清楚。
3. 文种规范：文种、结构和行文关系是否正确。
4. 语言克制：是否庄重、平实、简洁，无空洞 AI 腔。
5. 结构完整：标题、主送、正文、落款、日期等是否齐全。

低于 80 分时继续修改；如果缺少事实导致无法提升，停止编改并输出待补事实清单。

## 7. 输出与禁区

需要审计时保留下列内容：

- 文种与结构诊断
- 事实密度审计
- 最终候选稿
- 逐段修改原因
- 待补事实清单
- AI 痕迹和朱雀检测摘要
- 实际工具调用记录

禁止：

1. 编造数据、政策、人名、单位、时间或责任主体。
2. 改变原文核心事实、条件、例外、时态和责任边界。
3. 为通过检测牺牲公文庄重性或可读性。
4. 删除必要公文格式元素。
5. 把未调用的工具写成“已调用”。
6. 把朱雀分数当成作者身份或版权归属的确定性证明。
7. 未经授权把涉密、内部或个人敏感内容发送到外部检测服务。
